# Blustery Bulwark of SPLORR!!

A gale flattened yer farm. His Lordship says he did it. Climb his windy bulwark and have a word.

A tile-based roguelike metaphor by TheGrumpyGameDev, inspired by the kind of game Castle of the Winds was. Odin compiled to WebAssembly, drawn on a canvas. Work in progress: see `DESIGN.md` (the specification) and `PLAN.md` (the build plan).

```bash
tools/test.sh     # native tests, wasm checks and a build
tools/serve.sh    # build and serve on http://localhost:8000/
```
